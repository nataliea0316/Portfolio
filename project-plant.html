🌿 Plant Monitoring & Smart Watering

An IoT system that watches my plant’s soil moisture, waters it automatically and lets me check on it from a live web dashboard.

🧠 How It Works

  • An Arduino reads the soil sensor and sends the readings to a Raspberry Pi over serial.
  • When the soil gets too dry, the system waters the plant automatically.
  • A Flask web dashboard shows moisture in real time and sends push notifications.
  • Every reading is logged, building a dataset for future machine learning predictions.
  • systemd starts everything automatically when the Pi boots.

🔧 Built With

  • Python (Flask, threading, serial)
  • C++ (Arduino ADC, serial)
  • Linux (bash, systemd)
  • Raspberry Pi
  • Arduino

🎯 What I Learned

  • Debugging timing issues in serial communication.
  • Running and managing background services with systemd.
  • Collecting and preparing sensor data so a model can learn from it.
